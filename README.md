# 江苏省高校教师资格岗前培训刷题 PWA

## 直接使用（推荐）
本项目是纯静态网页，可部署到 GitHub Pages、Cloudflare Pages、Netlify 等 HTTPS 静态网站。

### GitHub Pages
1. 新建一个 GitHub 仓库，例如 `js-teacher-quiz`。
2. 把本压缩包内的所有文件上传到仓库根目录。
3. GitHub 仓库进入 Settings → Pages。
4. Source 选择 “Deploy from a branch”，Branch 选择 `main` / `(root)`。
5. 保存后等待页面给出 `https://你的用户名.github.io/js-teacher-quiz/`。
6. iPhone / iPad 用 Safari 打开该网址 → 分享 → 添加到主屏幕。

## 离线
首次在线打开后，Service Worker 会缓存题库和程序。之后从主屏幕图标进入，网络断开时仍可刷题。

## 本机数据
默认使用浏览器 localStorage 保存：作答记录、错题、收藏、掌握度、学习统计、每日学习记录等。

## 三端云同步（可选）
1. 创建 Supabase 项目。
2. 在 SQL Editor 运行 `supabase_schema.sql`。
3. 在刷题 App → “我的” → “Supabase 三端同步”中填写 Project URL、Anon public key、邮箱和密码。
4. 注册/登录后，可手动“上传进度”“下载进度”。

说明：题库中单选、多选原文主要是“题干 + 标准答案”，没有完整 A/B/C/D 原始选项。程序保留标准答案，并从同科目答案池生成干扰项。干扰项不是题库原文。

## 文件
- index.html：入口
- styles.css：iPhone / iPad / Mac 响应式界面
- questions.js：1100 道结构化题库
- app.js：刷题逻辑
- manifest.json：PWA 配置
- sw.js：离线缓存
- icons/：主屏幕图标
- supabase_schema.sql：可选云同步数据库表与 RLS


## 空白页修复说明
如果曾部署过旧版并出现空白页，本修复版已修正初始化顺序错误，并将离线缓存版本升级为 v4。上传覆盖 `app.js` 和 `sw.js`（推荐整体覆盖全部项目文件）后，刷新网页；若仍看到旧页面，可在 Safari/Chrome 关闭已安装的 PWA 后重新打开，必要时删除旧主屏幕图标并重新“添加到主屏幕”。


## v5 背题增强版
新增独立一级模块“背题”，底部导航为：首页 / 背题 / 刷题 / 错题 / 统计 / 我的。

背题支持：
- 随机背 20 题；
- 按科目、题型、学习状态分类背题；
- 今日复习、错题背诵、收藏背诵；
- 题干挖空主动回忆；
- 显示题库标准答案、题库原文和辅助记忆；
- 自评“不认识 / 有印象 / 已掌握”，自动更新复习计划；
- 一轮背题完成后，可直接用同一组题进入“刷题”或“模拟测试”；
- 首页增加“背题 → 刷题 → 模拟考试”三阶段学习路径。

更新 GitHub Pages 时，建议覆盖所有文件，尤其是 `app.js`、`styles.css`、`sw.js`。本版 Service Worker 缓存号为 `teacher-quiz-pwa-v5-recite`。


## v6 Mac / iPad 横屏自适应修复
针对桌面端左侧导航遮挡内容的问题重新设计响应式断点：

- `< 900px`：底部导航，适合 iPhone / iPad 竖屏；
- `900–1279px`：自动收缩为约 78px 的窄侧栏，适合较窄 Mac 窗口和 iPad 横屏；
- `>= 1280px`：自动展开为约 184px 的完整侧栏；
- 主内容区域不再使用会导致侧栏错位的固定居中偏移，内容宽度始终扣除侧栏宽度；
- 小尺寸桌面窗口下，快捷入口、统计卡片、科目列表、模拟考试表单会自动降列，避免横向挤压；
- Service Worker 缓存升级为 `teacher-quiz-pwa-v6-responsive-desktop`，覆盖 GitHub Pages 后可强制获得新 CSS。


## v7 高仿真干扰项优化
本版针对“混淆答案与正确答案差异过大”的问题，重构了选择题选项生成机制。

- 共处理选择题：900 题（单选 800，多选 100）；
- 判断题 200 题不需要干扰项；
- 每道选择题现在都有固定的 `distractors` 字段；
- 不再把整科中随机答案直接拿来做混淆项；
- 人物题优先匹配人物，时间题匹配相邻年份/世纪，理论题匹配相近理论，方法题匹配同类方法，评价/强化/迁移等概念按同一知识家族生成；
- 对无法归入明确概念家族的题目，使用“题干语义相似 + 答案表面相似 + 长度相似”联合排序；
- 原题库的 `answerText` / `answerParts` 没有被改写。

注意：原上传题库主要提供“题干 + 标准答案”，并未提供完整 A/B/C/D 官方选项，因此本版混淆项属于训练重构项，目的在于提高辨析难度，不能视为官方原始选项。
